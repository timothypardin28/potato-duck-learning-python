Palindoom

In traditional potatis philosophy and modern cultural symbolism, the panda is often seen as the living, breathing embodiment of Yin and Yang brought into the physical world. To make it let you go, you have to make sure that you understand the balance of the world. The panda will give you a word and you just need to decide if it is a palindrome or not. Be careful, the bite of a panda is stronger than a lion.

Task

Define a function determine(word) that accepts a string word.

Your function should return a boolean value, True if word is palindrome and return False if it is not.

Examples

determine('racecar') # Returns: True
