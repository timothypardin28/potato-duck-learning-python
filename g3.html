7 Floating Alphabet

PyThorn's curse makes every rock to echo, but stepping on too many vowel steps will shatter the glass. To get across safely, Quackbit has to count the vowels of every possible path to ensure it's no more than 3 vowels.

Task

Define a function cross_floating_alphabet(path) that accepts a string path.

Your function should return the number of vowels if the path is valid and return -1 if it is an invalud path.

Examples

cross_floating_alphabet('potatis') # Returns: 3

Guidelines

Try to list the requirement in terms of variable and value pair first before writing the program.
