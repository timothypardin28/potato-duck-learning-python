Boss Story

The Pythorn

To start the journey, Quackbit has to overcome the first guardian. The Jumping River. This is the river that separates the village from the dark path to the PyThorn nest. There is no bridge in sight. The only way across is a long line of mossy, floating stones.

Boss

The Pythorn

The stones are numbered sequentially from 1 to the far shore. However, PyThorn applied a defense mechanism into them: every odd-numbered stone is a trap, while every even-numbered stone is solid and safe. To cross safely, Quackbit must JUMP over the odd stones and STEP only on the even ones.

Task

Define a function jump_or_step(stone_index) that accepts an integer stone_index.

Your function should return the string 'JUMP' if the stone_index is odd and return the string 'STEP' if it is even.

Examples

jump_or_step(5) # Returns: 'JUMP'

Guidelines

Think about how do you usually determine a number is even or odd
