Two Pair

Blocking the path forward is a massive iron door. In the middle of the door, a central rune displays a number, flanked by two keyholes, one large hole and one small hole. To unlock the door, Quackbit must grab two keys whose numbers add up exactly to the door's target number.

Task

Define a function findPair(runeList, target) that accepts a list runeList and an integer target.

Your function should return the string a list [large_rune, small_rune], return -1 if the is no suitable pair of runes.

Examples

findPair([23, 21, 1, 45, 9, 3, 16], 57) # Returns: -1 findPair([3, 4, 2, 5], 7) # Returns: [5, 2]

Guidelines

Think about how to find the pair that add up to target value without iterating through the list for each number.
