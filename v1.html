Village 1 • Conditionals

The Decision

Let's say you're walking straight and there is an wooden sign in the middle of the road. There are two signs, one is a road leading to a dead end occupied by bandits and the other is a road leading you to a safe shelter. After seeing the sign, how should you make your decision?

Task

Define a function decide_based_on(sign) that accepts a string sign.

Your function should return the string 'keep going' if the sign equals 'shelter'. Return 'turn back' if sign equals 'bandits'. Other than that, return 'ask someone'

Examples

decide_based_on('shelter') # Returns: 'keep going'
