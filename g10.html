Guardian 10 • 2D Binaary Search

Fast, We're Running Out of Time!

It doesn't attack with force, it attacks your mind. The Keeper flashes an ancient counter curse ID code on the wall for a fraction of a second, then plunges the room into complete darkness. You must recall the target code and search through thousands of sorted crystal records to find its exact index position before the platform collapses into the void. Don't take too long or you will stay here forever.

Task

Define a function findloc(curseID, matrix) that accepts an integer curseID and a 2D matrix called matrix.

Your function should return the index of the curseID in the form of list [i-th row, j-th col].

Examples

findloc(20, [[1, 5, 9], [14, 20, 25], [30, 45, 60]]) # Returns: [1, 1]

Guidelines

2D matrix size grows quadratically, make sure not to look for the matrix entry one by one.
