Fuzzy Talking Wall

According to the Book of Potatis, this wall was once an old mongoose who fought PyThorn for three days. In the end, the mongoose was defeated and was cursed into a wall. To pass, Quackbit simply has to repeat the words spoken by the wall. However, the voice is muffled and full of noisy symbols. Quackbit must write a script to clear away all the fuzz and say the true word back!

Task

Define a function analyze(word) that accepts a string word.

Your function should removes all non-alphabetic characters/symbols, and returns the cleaned directional string.

Examples

analyze('#S@t1a2r3t#') # Returns: 'start'

Guidelines

Try to use Python built-in function instead of manually handle it.
