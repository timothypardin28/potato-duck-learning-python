Existing Spell

After you have a long journey, your inventory gets a bit messy, the item just spreads across the whole inventory without any grouping or section. You want to make it tidy ordered from the highest value item to the lowest value item but you're just too lazy to do it manually. You're wondering if there is any spell that you can use to instantly sort them.

Task

Define a function tidy_up(inventory) where inventory is a Python dictionary with item names as keys and integer values as the value of the item.

Your function should order the item from the highest to the lowest value and return the dictionary. If the dictionary is empty, return 0.

Examples

tidy_up({"corn": 100, "potato": 150, "berries": 50}) # Returns: {"potato": 150, "corn": 100, "berries": 50}

Guidelines

Besides spells by other coders, you can also create your own, who knows your spell might help the future protector of this village. It's very simple, you just need to enveloped the block of code inside a def function_name(parameter):, then you just need to write function_name(parameter) to use the spell.
