The Echoing Gate

Quackbit arrives at the iron gate of PyThorn’s ruin. The gate is guarded by ancient acoustic runes that echo magical spells into the air.

Guardian 7 • Loop & Function

The Echoing Gate

To break PyThorn's seal, Quackbit must listen to an echoed spell string and find the FIRST non-repeating character (the single rune that speaks only once). If every single character in the spell repeats, or if the spell is empty, the door remains locked, and Quackbit must return "LOCKED".

Task

Define a function pullOne(word) that accepts a string word.

Your function should return the first non-repeating letter in word. If there is no non-repeating letter or word is empty, return 'LOCKED'

Examples

pullOne('waterbitwater') # Returns: 'b'
